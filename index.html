DETAILED SYLLABUS

Course Coverage & Practical Labs

Click on any module to explore topics, tools used, and lab details included in the 150 hours of offline training.

Module 01

Network Fundamentals

Understand how networks operate. Master the foundations of computer communication and the stack layers that enable global connectivity.

Key Topics Covered

  • TCP/IP and OSI Reference Models
  • Roles of Routers, Switches, Endpoints, and Servers
  • Network Topologies & Physical cabling (Fiber, Copper, Wireless)
  • Introduction to WAN, LAN, and Cloud models

Hands-on Practical Labs

Setting up basic physical cabling, mapping out LAN layouts, and establishing simple host-to-host connectivity using Cisco terminal consoles.

Cisco CLI Physical RJ-45 Crimping Tool
Module 02

IPv4 & IPv6 Addressing

Deep dive into IP addressing architectures. Learn to catalog, allocate, and plan address spaces for various sizes of enterprises.

Key Topics Covered

  • Structure of IPv4 addresses & Classful vs Classless addressing
  • Private vs Public IP addresses (NAT/PAT concepts)
  • IPv6 addressing format, abbreviation, and prefix types
  • Dual-stacking, tunneling, and translation

Hands-on Practical Labs

Configuring static IP addresses on endpoints and router interfaces. Setting up dual-stack IPv4/IPv6 networks and confirming cross-protocol pings.

Cisco IOS Configuration Wireshark Packet Sniffing
Module 03

Subnetting Mastery

Develop speed and accuracy in dividing IP address ranges. Ensure zero address waste and optimal broadcast domain boundaries.

Key Topics Covered

  • Binary arithmetic for networking professionals
  • Variable Length Subnet Masking (VLSM) algorithms
  • Calculating network addresses, broadcast addresses, and usable ranges
  • Summarizing subnets to reduce routing table overhead

Hands-on Practical Labs

Intensive offline workshops solving real-world subnet planning case studies. Configuring subnets across large multi-department networks on Cisco Packet Tracer.

VLSM Calculators Cisco Packet Tracer Simulation
Module 04

VLAN & Switching Basics

Segment local networks securely. Master layer 2 connectivity, traffic isolation, and redundancy protocols.

Key Topics Covered

  • Broadcast domains separation using Virtual LANs (VLANs)
  • 802.1Q Trunking protocols and DTP concepts
  • Inter-VLAN Routing (Router-on-a-Stick & Layer 3 Switches)
  • Spanning Tree Protocol (STP) and Rapid STP concepts

Hands-on Practical Labs

Creating VLANs, assigning ports, creating 802.1Q trunks, configuring sub-interfaces on routers, and troubleshooting STP topology loops on physical Catalysts.

Cisco Catalyst 2960/3560 Switches Inter-VLAN trunks
Module 05

Routing Protocols (OSPF)

Configure dynamic path discovery to make networks resilient and highly scalable using link-state routing.

Key Topics Covered

  • Static vs Dynamic Routing mechanisms
  • Link-State routing concepts and Dijkstra's algorithm
  • Single-area and Multi-area OSPF v2 & v3
  • OSPF neighbor states, DR/BDR election, metrics, and configuration

Hands-on Practical Labs

Setting up OSPF on multi-router topologies. Modifying interface costs to influence pathways, and resolving OSPF neighbor adjacency failures on real-world Cisco routers.

Cisco 1941/2911 Routers Routing Table Diagnostics
Module 06

Network Security Principles

Secure the edge. Prevent unauthorized network access, isolate threats, and implement device hardening policies.

Key Topics Covered

  • Threat landscape: DoS, spoofing, man-in-the-middle
  • Port Security on Access Switches (Static, Sticky, Violation actions)
  • Standard and Extended Access Control Lists (ACLs)
  • AAA framework (Authentication, Authorization, Accounting)

Hands-on Practical Labs

Implementing Port Security to lock down Ethernet ports, writing extended ACL rules to block specific ports (e.g. HTTP, SSH) while permitting pings.

Switch Port Security Access Control Lists (ACL)
Module 07

Wireless Networking

Understand mobility architectures. Set up secure enterprise wireless environments supporting hundreds of clients.

Key Topics Covered

  • AP Modes: Autonomous vs Lightweight APs
  • Wireless Lan Controller (WLC) management architectures
  • WPA2/WPA3 encryption and enterprise authentication
  • RF bands, channels, and interference mitigation

Hands-on Practical Labs

Accessing and configuring a mock Cisco WLC GUI, establishing SSIDs, mapping them to specific VLANs, and authenticating remote clients using WPA2-Enterprise.

Cisco WLC GUI Console Lightweight Access Points
Module 08

Automation & Programmability

Transition to modern software-defined workflows. Learn to configure networks using scripts and APIs rather than single CLI entries.

Key Topics Covered

  • Controller-based networking vs traditional management
  • REST APIs & JSON data formats for network status
  • Configuration management tools (Ansible, Puppet, Chef basics)
  • Cisco DNA Center (Catalyst Center) features

Hands-on Practical Labs

Parsing JSON device configurations, executing mock REST API GET calls to gather network interface reports, and writing basic Ansible Playbooks to roll out VLANs.

Python / Ansible scripts REST client / Postman API
